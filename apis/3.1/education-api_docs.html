Beschrijving

The Education API is implemented by the Administratiesysteem onderwijsdeelnemer.

The Education API has the following objects:

  • Organisation: school organisations
  • StudyOffering: the study units including the study year offered by a school
  • SubjectOffering: the subjects offered by a school

These objects could be considered open data from the school. As a data owner, the school authorizes the exchange of this information towards suppliers.
A possible implementation for an Administratiesysteem onderwijsdeelnemer is to offer an open data option to the school.
This option means that a reference component that is allowed to consume the Education API to request data without the consent mechanism.

The Education API has a scope of primary and secondary education. Vocational education is out of scope. For Vocational Education we advise to use the Open Education API (OOAPI).

Functional status code and status message.

VeldTypeV/OOmschrijving
status integer V Functional status code, as defined in "Status- en foutcodes 1.0.0". Codes are sent as integers without leading zeros (0011 = 11). Algemeen (00xx) - applies to every API: * 0000 - OK: Bevraging succesvol (HTTP 200). * 0001 - Created: Bericht heeft geleid tot registratie van een nieuwe entiteit (HTTP 201). * 0002 - Accepted: Bericht geaccepteerd (HTTP 202). * 0011 - Schema incorrect: Schemavalidatie niet succesvol (HTTP 400). * 0012 - schemaVersion not supported: De ontvanger kan de gehanteerde schemaVersion niet verwerken (HTTP 400). * 0021 - scope required: Leverancier is niet geautoriseerd voor scope (HTTP 401). * 0022 - consent required: Informatieobject van classificatie IV zonder geactiveerde gegevensdienst (HTTP 403). * 0023 - school unknown: De client communiceert in de context van een Onderwijsorganisatie die niet bekend is bij de server (HTTP 400). * 0099 - Overige reden: Vullingsregel: neem in statusMessage een beschrijving van de reden op. Education API (20xx): * 2001 - School unknown: De identifier van de onderwijsorganisatie is onbekend. * 2002 - SubjectOffering unknown: De identifier van het SchoolVak is onbekend. * 2003 - StudyOffering unknown: De aangeboden opleiding is onbekend. * 2008 - SchoolPeriod unknown: De identifier van de schoolperiode is onbekend. * 2011 - Board unknown: De identifier van de board is onbekend.
statusMessage string O See functional status messages within the Documentation.
